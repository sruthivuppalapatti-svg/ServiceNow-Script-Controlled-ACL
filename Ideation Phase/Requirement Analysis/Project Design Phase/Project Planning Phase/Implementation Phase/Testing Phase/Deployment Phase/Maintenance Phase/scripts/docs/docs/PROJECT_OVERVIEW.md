# Script Controlled ACL System

## Project Overview

This project demonstrates the use of Access Control Lists (ACLs) to manage file permissions through a shell script.

## Objective

The main objective is to provide controlled access to files based on user requirements.

## Features

- User-based access control
- File permission management
- ACL permission checking
- Script-based automation
- Access verification

## Technologies Used

- Linux
- Bash Shell
- ACL
- GitHub

## Working

The script accepts a username and file name from the user and displays the existing ACL permissions.

ACLs can then be used to provide specific read, write and execute permissions to users.

## Expected Outcome

The system provides a simple method for managing and checking file access permissions using ACLs and shell scripting.
