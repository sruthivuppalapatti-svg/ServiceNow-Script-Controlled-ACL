# Implementation Phase

## 1. Introduction

The implementation phase is the stage where the designed system is converted into a working project.

The Script Controlled ACL system is implemented using scripts to control and manage access permissions for files and users.

## 2. Implementation Process

The main implementation activities are:

- Creating the required project files.
- Writing the access control script.
- Creating users and groups.
- Assigning permissions.
- Applying Access Control Lists (ACLs).
- Testing the assigned permissions.
- Checking whether unauthorized access is prevented.

## 3. Script Controlled ACL

The script is used to automate the process of managing file access permissions.

It can:

- Identify the user.
- Identify the required file.
- Assign appropriate permissions.
- Modify ACL entries.
- Verify the assigned permissions.

## 4. Access Control

Access permissions are provided based on the requirements of each user.

The main permissions are:

- Read
- Write
- Execute

ACLs provide more detailed control over file access than normal file permissions.

## 5. Testing

The implemented system is tested using different users and permission levels.

Testing verifies that:

- Authorized users can access the required files.
- Users receive only their permitted permissions.
- Unauthorized users cannot access restricted files.
- ACL rules are correctly applied.

## 6. Expected Result

The implementation should provide controlled and secure access to files.

The system should automatically apply the required ACL permissions through the script and prevent unauthorized access.
