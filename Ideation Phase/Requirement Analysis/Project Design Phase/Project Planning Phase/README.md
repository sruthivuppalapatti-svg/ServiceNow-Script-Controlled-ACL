# 4. Project Planning Phase

## Project Goal

To develop a ServiceNow-based access control system that restricts record access according to specific field values.

## Project Plan

The project was planned and completed in the following stages:

1. Create required users.
2. Create required roles.
3. Create the required tables.
4. Configure READ ACL.
5. Configure CREATE ACL.
6. Configure WRITE ACL.
7. Configure DELETE ACL.
8. Test the access restrictions.
9. Document the completed project.

## Team Responsibilities

The team members worked together to design, develop, test and document the project.

## Testing Plan

The ACL rules are tested using different users and field values to verify that authorized users can perform permitted operations and unauthorized users are restricted.

## Expected Outcome

The completed system should provide controlled and secure access to ServiceNow records based on the defined field values and ACL conditions.
